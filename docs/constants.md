# Реестр констант

Все фиксированные числа программы: значение, единица, происхождение и смысл. Документ создан командой
`python -m scene_editor constants --output docs/constants.md`; тесты проверяют, что он совпадает с кодом и что в коде
нет числовых констант без описания.

Происхождение: **измерено** — посчитано по реальным данным, источник назван; **подобрано** — выбрано
вручную на эталонных данных и проверено просмотром и тестами; **внешнее** — взято из другой системы для
согласованности; **ограничение** — предел объёма работы или размера; **определение** — задано форматом
или смыслом параметра.

Значения в каналах и опросах подобраны на эталонном наборе (линия 40 каналов, кадры 40 опросов).

## morph.py

| Константа | Значение | Единица | Происхождение | Смысл |
|---|---|---|---|---|
| `TAU` | 0,1 | доля шкалы | измерено | Порог «объект/фон»: 99 % пикселей фона ниже 0,086 (real_data, train, 18.10.2026; docs/synthetic_data_method.md, п. 2.3). |
| `SIGNAL_FLOOR` | 0,012 | доля шкалы | подобрано | Значения нового объекта ниже этого обнуляются как «хвосты» интерполяции: 3 уровня из 255, на уровне среднего фона (0,013; п. 2.3 методики). |
| `SWINGING_MIN_LENGTH` | 5 | опросы | подобрано | Вид «качание»: извилистость следа оценивается только при длине не меньше этой. |
| `SWINGING_WIGGLE` | 0,55 | каналы | подобрано | Вид «качание»: СКО бокового следа от его квадратичного приближения не меньше этого. |
| `ROLLING_EXCURSION` | 2,5 | каналы | подобрано | Вид «перекатывание»: боковой ход следа за время прохода не меньше этого. |
| `ROLLING_WIDTH` | 7 | каналы | подобрано | Вид «перекатывание»: след такой ширины и шире уже сместился поперёк линии. |
| `LONG_LENGTH` | 11 | опросы | подобрано | Вид «длинный» (медленный проход): длина не меньше этой. |
| `SHORT_LENGTH` | 4 | опросы | подобрано | Вид «короткий» (быстрый проход): длина не больше этой. |
| `EDGE_TOLERANCE` | 1 | ячейки | внешнее | Рамка ближе этого к краю кадра считается обрезанной краем (TOUCH_TOLERANCE в SensorLine, sensorline/border.py). |
| `MIN_KIND_OBJECTS` | 5 | объекты | подобрано | Меньше реальных объектов вида — фильтр не сравнивает новые объекты этого вида с реальными. |
| `RANGE_PERCENTILES` | 1…99 | процентили | подобрано | Диапазон признака реальных объектов вида: между этими процентилями (крайние 1 % — выбросы). |
| `NEAREST_PERCENTILE` | 95 | процентиль | подобрано | Типичное расстояние реального объекта до ближайшего реального соседа того же вида (в масштабе признаков). |
| `TEXTURE_BINS` | 0,1, 0,25, 0,5, 0,75, 1,01 | доля шкалы | подобрано | Полосы интенсивности, в каждой из которых восстанавливается мелкий шум реальных объектов. |
| `BLOB_RATIO` | 1,25…5 | длина/ширина | подобрано | Допустимое отношение длины к ширине нового «обычного» объекта, выбрано по реальным: медиана 2,0, 5–95 % между 1,5 и 3,0, не выше 5 (значение по умолчанию, меняется в интерфейсе). |
| `MAX_VALLEY` | 0,5 | доля | подобрано | След не должен проседать ниже этой доли более слабой из двух сторон: иначе он разорван. |
| `RANGE_MARGIN_BOUND` | 0,15 | доля | подобрано | Фильтр: признак может выйти за реальный диапазон на эту долю границы ... |
| `RANGE_MARGIN_SPREAD` | 0,25 | доля | подобрано | ... плюс эту долю межквартильного размаха признака (запас для признаков около нуля). |
| `NEAREST_FACTOR` | 1,5 | раз | подобрано | Фильтр: ближайший реальный объект может быть дальше типичного (NEAREST_PERCENTILE) не более чем во столько раз, иначе объект «не похож на реальные». |
| `COPY_SIMILARITY` | 0,97 | корреляция | подобрано | Фильтр: при большем сходстве с исходным объектом (после приведения к общему размеру) новый — копия. |
| `NEUTRAL_IMPERFECTIONS` | noise 0, hotspot 0, hotspot_angle 0, hotspot_offset 0,6, stripes 0, dropout 0, seed 0 | — | определение | Нейтральные значения несовершенств нового объекта. |
| `IMPERFECTION_BOUNDS` | noise 0…1, hotspot 0…1, hotspot_angle -360…360, hotspot_offset 0…1, stripes 0…1, dropout 0…1 | — | ограничение | Допустимые диапазоны несовершенств нового объекта. |
| `DRAW_ATTEMPTS_MIN` | 200 | попытки | ограничение | Наименьшее число попыток получить новые объекты. |
| `DRAW_ATTEMPTS_PER_OBJECT` | 30 | попытки | ограничение | Попыток на каждый запрошенный новый объект. |
| `SIFT_SHARE` | 0,1 | доля | подобрано | Отсев мелких: доля самых коротких и, отдельно, самых узких новых объектов партии. |
| `SIFT_SHARES` | length 0,1, width 0,1 | доля | подобрано | Отсев мелких по длине и ширине (из SIFT_SHARE). |
| `FAINT_SIFT_SHARES` | area 0,1, brightness 0,2 | доля | подобрано | Перекатывание и качание: также доля самых малых по площади и самых тусклых. |
| `SIFT_MIN_BATCH` | 10 | объекты | подобрано | Партия меньше этого не отсеивается. |
